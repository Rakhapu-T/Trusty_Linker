# 2. The Development Roadmap

| **Phase**           | **Task**                                                 | **Key Tool**                         |
| ------------------- | -------------------------------------------------------- | ------------------------------------ |
| **1. Logic**        | Wrap your library commands into clean Python functions.  | Standard Python                      |
| **2. UI Design**    | Create the buttons/inputs that trigger those functions.  | CustomTkinter or PyQt                |
| **3. Environment**  | Use a Virtual Environment to keep the bundle size small. | `venv` or `conda`                    |
| **4. Freezing**     | Package the code into an executable file.                | PyInstaller                          |
| **5. Distribution** | Create an installer for users to download.               | Inno Setup (Win) or DMG Canvas (Mac) |
